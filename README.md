## 简介

观象是一个 **DeepSeek Harness（DSH）Web 插件**，也可以作为独立的本地 Web 应用运行。支持 **八字、星座、塔罗、扑克、姓名、易卦、紫微斗数、求签**，每种方式都有专属界面与分析 Skill。

| 能力 | 使用体验 |
| --- | --- |
| ☯ 多种命理体系 | 程序生成盘面与抽取结果，DeepSeek 结合问题解读 |
| ☾ 简洁界面 | 浅色 / 深色主题、响应式布局与抽牌动效 |
| ◷ 历史留存 | 自动保存盘面、解读与时间戳，支持搜索、分页、单条删除和 JSON 导出 |
| ✧ 用量可见 | 结果底部展示实际 token 消耗与费用估算，缓存读取不再次调用 AI |
| ↗ 多设备访问 | 本机启动，手机或其他电脑通过局域网地址直接进入 |

各体系的流派、计算依据与边界见[规则说明](docs/rules.md)。解读供文化探索与自我反思参考。

## 环境安装

1. 安装 [Node.js](https://nodejs.org/) **22.13 或更新版本**，并确保 `node`、`npm` 可在终端运行。
2. 下载或克隆本项目，在项目根目录操作。
3. 准备 DeepSeek API Key；首次启动需要联网安装依赖，AI 解读也需要联网。本地排盘可离线使用。

可在终端检查环境：

```bash
node --version
npm --version
```

无需单独安装数据库，也无需构建前端；启动脚本会在依赖缺失时自动安装运行依赖。

## 快速使用

### 方式一：独立启动

| 环境 | 启动方式 |
| --- | --- |
| Windows | 双击项目根目录的 `start.bat` |
| Linux | 在项目根目录执行 `bash start.sh` |
| 已安装依赖 | 执行 `npm start` |
| 无桌面服务器 | 执行 `bash start.sh --no-open` |

启动后会自动打开浏览器。本机默认地址为 **`http://localhost:3210`**，打开即可使用，无需登录。保持服务运行，按 **Ctrl+C** 停止。

### 方式二：作为 DSH 插件运行

在已有 Harness CLI 的环境中，使用项目的绝对路径安装：

```bash
dsh plugin --profile web add /绝对路径/fortuneteller
dsh web
```

然后从 DSH 输入区下方的「打开观象工作室」入口进入。插件会自行启动工作室服务，**此时不用再启动 `start.bat` / `start.sh`**。端口、数据目录与兼容性说明见 [DSH 接入指南](docs/harness.md)。

### 开始第一次探索

1. 打开「设置与连接」，填写 **DeepSeek API Key** 并保存。
2. 在探索页选择一种方式，填写信息或问题，生成盘面。此步骤在本地完成，不消耗 AI tokens。
3. 点击「开始 DeepSeek 解读」，查看解读及底部的 token / 费用小字明细。
4. 在「历史记录」重新查看、搜索、删除或导出结果；已完成的解读会直接读取缓存。

手机或其他电脑连接同一局域网，打开**页面顶部「局域网访问」**显示的 `http://192.168.*:端口` 地址，即可直接使用，无需登录。地址可一键复制，启动终端也会同步显示。所有访问设备共享记录、设置与 API 调用额度；跨设备访问需允许服务端防火墙的可信局域网 TCP 3210 入站。

需要改端口、使用环境变量或调整单价？请查看[环境与配置](docs/configuration.md)和[费用说明](docs/billing.md)。

## 问题解决

| 遇到的问题 | 解决方法 |
| --- | --- |
| 找不到 Node.js，或版本过低 | 安装 Node.js ≥22.13，重新打开终端，确认 `node --version` |
| 依赖安装失败 | 确认能访问 npm registry，在项目根目录执行 `npm ci --omit=dev` 后重试 |
| 浏览器没有自动打开 | 手动访问 `http://localhost:3210`即可使用 |
| 提示端口已占用 | 关闭之前启动的观象服务；独立模式也可在 `.env` 中修改 `PORT`，插件模式修改 `config.port` |
| 手机无法访问 | 使用终端打印的局域网 IP，确认设备在同一局域网、监听地址为 `0.0.0.0`，且防火墙允许入站 |
| API Key 无效、余额不足或请求过频 | 检查设置中的密钥、DeepSeek 账户余额；限流时稍后重试 |
| 解读超时或网络失败 | 检查服务端网络，在历史记录中重试同一盘面；重试会重新调用 API |
| 模型选项无法切换 | 如设置了 `DEEPSEEK_MODEL`，移除该环境变量并重启服务 |
| 更新后仍显示旧登录页 | 重启服务并刷新页面，必要时强制刷新；新版本打开即可使用 |

详细排查步骤见[故障排查](docs/troubleshooting.md)；历史备份和数据位置见[数据管理](docs/data.md)。
