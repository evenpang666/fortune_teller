# 使用指南

[返回首页](../README.md) · [文档目录](README.md) · [安装与启动](getting-started.md)

## 完成一次探索

1. 在探索页选择八字、星座、塔罗、扑克、姓名、易卦、紫微斗数或求签。
2. 按页面提示填写信息和问题，生成盘面。本地排盘、抽牌与起卦不调用模型。
3. 点击解读，观象通过 DSH 的默认模型生成内容，并保存盘面、解读与返回的实际用量。
4. 在「历史记录」中重新打开、搜索或筛选记录。已完成的解读直接使用缓存，不再次调用模型。

解读失败时可以从同一记录重试，无需重新排盘或抽牌；重试会产生新的模型请求。费用显示为估算值，口径见[Token 与费用](billing.md)。

## 今日黄历与姓名笔画

首页「今日运势」按需展开，展示按北京时间更新的黄历与当天提示，不调用 AI。

姓名页面支持单姓与复姓，输入姓名后自动查询姓名学康熙笔画。字形有差异或未收录时，可核实后手动调整。数据来源与边界见[姓名与康熙笔画](name-strokes.md)。

## 分享与整理

记录详情中的「分享盘面」可保存独立 HTML 网页，包含当时的盘面、问题与已有解读，支持离线阅读；也可复制记录链接，接收者需能访问同一 DSH Web 并通过认证。

历史列表、首页最近记录和详情页均可删除记录，确认后会同时移除对应盘面与解读。备份、分享与共享访问的具体行为见[数据管理](data.md)。

## 模型与界面偏好

API Key、模型提供方、服务地址和默认模型在 DSH Web 的模型设置中管理。修改默认模型后，下一次新解读生效；已有解读保留原模型与用量。观象设置页用于调整费用估算单价，主题按钮可切换浅色与深色。

各体系的规则、时间口径与限制见[规则与 Skill](rules.md)。解读用于文化探索与自我反思，不作为确定的预测。
