# 历史记录、备份与访问

[返回项目首页](../README.md) · [文档目录](README.md)

## 保存与缓存流程

1. 在探索页选择命理形式，填写该体系的信息和问题。
2. 程序在本地完成排盘、投币或不放回抽牌，立刻写入历史记录，不调用 AI。
3. 点击「开始 DeepSeek 解读」，服务端加载专属 `SKILL.md`，将本次输入和结构化盘面发送给 DeepSeek 官方 API。
4. 完成后，解读、真实 usage、费用估算、模型、完成时间和当次单价快照写入同一记录。读取已完成记录或重复点击同一记录的分析接口直接返回缓存，不再次调用 API。

失败会保留原始盘面与错误状态；重试不会重新抽牌，但会重新调用 API。服务重启会将中断的 `analyzing` 记录转为可重试状态。分析最多并发三条，单次请求超时 120 秒；同一记录不能并发解读或在解读中删除。浏览器断开后，服务端仍会完成请求并缓存结果。

## 数据文件与访问机制

- SQLite：`.data/readings.sqlite`（含 WAL 文件）；UTC ISO 时间戳存储，浏览器按设备当地时间显示。
- 配置：`.data/config.json`。目录/敏感文件在支持的系统上使用限制权限，API Key 不通过读取配置接口回传。
- 打开本机或局域网地址即可使用，无需口令、登录或会话 Cookie。服务仍核验 Host/Origin，阻止不匹配的跨站来源。
- **共享工作室**：所有可访问服务的设备共享全部记录、配置和 API 调用额度，暂未实现多人账户隔离。HTTP 面向可信局域网，公网场景请另行部署 HTTPS/身份服务。
- 浏览器主题偏好存入 localStorage；排盘和解读均由服务端 SQLite 持久化，清除浏览器缓存不会丢失历史。
- 备份时先停止服务，再复制完整 `.data` 目录。旧版本的 `access-token` 文件已不再使用，新版本不会生成或读取该文件。

## 独立模式与插件模式

独立模式默认使用项目目录的 `.data/`；DSH 插件默认使用其启动目录中的 `.data/fortuneteller/`。文件名和结构相同。若需要共享历史，可将两种模式的 `FORTUNE_DATA_DIR` 指向同一个绝对路径，并只运行一个服务。配置示例见[环境与配置](configuration.md)。

## 搜索与分享

历史页按创建时间倒序展示，每页最多 200 条，通过「加载更多记录」继续查看。搜索覆盖全部存档，可按命理形式筛选。打开单条记录，点击「分享盘面」可保存独立 HTML 网页，包含盘面、问题、关键信息解读与实践建议；尚未解读的记录仅保存盘面和问题。样式内嵌，离线即可查看，可把 HTML 文件发送给他人。网页为保存当时的快照，后续解读或删除不会改动已保存文件。

分享窗口也可复制记录链接，优先采用本机局域网地址；接收者需能访问该工作室，服务需保持运行。链接展示当前记录，删除后失效。JSON 导出入口与批量导出接口已移除。

## 删除记录

历史记录列表和首页的「最近的探索」中，每条记录右侧都有「删除」按钮；详情页也保留「删除这条记录」入口。点击后会显示该记录的问题或盘面摘要，确认才会删除。取消或按 Esc 会保留记录。

删除会一并移除该记录的输入、排盘、解读与用量数据，历史不再包含它，已复制的记录链接也会失效。当前列表与计数会更新，并保留搜索/类型筛选条件。局域网设备使用同一数据库，因此删除对所有设备生效。分析中的记录暂不能删除，删除失败时会保留记录并显示错误。
