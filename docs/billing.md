# DeepSeek Token 与费用估算

[返回项目首页](../README.md) · [文档目录](README.md)

当前模型取自 DSH 默认选择；观象本地费用配置初始对应 `deepseek-flash`。按 [DeepSeek 官方价格表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（2026-10-14 核对）默认采用人民币高峰单价：

| 模型 | 输入缓存命中 / 百万 | 输入未命中 / 百万 | 输出 / 百万 |
| --- | ---: | ---: | ---: |
| Flash | ¥0.04 | ¥2 | ¥8 |
| V4 Pro | ¥0.30 | ¥9 | ¥27 |

空闲时段通常减半；默认估算不会自动判断法定节假日/供应商时段，设置页可修改单价，以平台实际账单为准。使用 DSH 流中的 `inputTokens`、`outputTokens` 和缓存计数，按缓存命中、未命中与输出分别计价。未返回 usage 时显示未知，不虚构用量；请求失败或中断时可能已发生费用，但未取得的 usage 无法统计。每条已完成记录以小字显示明细和估算口径。

费用公式：`(命中 tokens × 命中单价 + 未命中 tokens × 未命中单价 + 输出 tokens × 输出单价) / 1,000,000`。

## DSH 插件模式

解读通过 DSH 的生成服务调用其默认模型。用量来自宿主流，DSH 的未缓存输入、缓存读取和缓存写入为分离计数；页面将其归并为总输入、缓存命中和未命中，避免缓存重复计数。

费用单价仍为观象本地估算配置；保存单价时会关联当前 DSH 默认模型。只有 `deepseek-official` 且模型与本地单价对应模型一致时估算费用；其他提供方或模型仅展示返回的 token 用量，避免套用 Flash 价格。缺失用量时不编造 token 或金额，模型端账单为准。
