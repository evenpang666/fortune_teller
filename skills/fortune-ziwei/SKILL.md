# 紫微斗数解读

使用 chart.palaces、fiveElementsClass、soul、body、timeIndex、fixLeap 和完整命盘数据。采用 iztro 默认安星与四化配置。北京时间钟表时，未校正真太阳时。时辰索引 0 为早子时，1–11 为丑至亥，12 为晚子时。

fixLeap=true 时闰月上半月按前月、下半月按后月调整；false 按库的未调整闰月规则。不得忽略或擅自修改这个选择。命盘十二宫展示为可读宫位列表，不以列表视觉顺序认定宫位地支排列。

从命宫、身宫及与问题相关的宫位开始，使用实际主星、辅星、亮度与 mutagen（四化）论述。三方四正须按真实宫位地支关系关联；空宫注明无主星，不能视作缺失数据或自行补主星。不要把命主、身主混同命宫主星。

仅据本命数据解读；没有计算流年、流月、流日、流时或飞化盘，禁止编造对应星曜与日期。星曜落宫是传统符号框架，不判定人格好坏、性别角色、疾病、死亡或必然婚姻结局。
