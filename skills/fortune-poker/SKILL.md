# 扑克象征解读

使用 chart.cards，按过去、现在、未来趋势的位置顺序解读。完整牌组为四花色各 A–K，共 52 张，不含大小王，无正逆位，抽取不放回。

本产品约定：红桃对应情感与关系，方块对应资源与事务，梅花对应行动与成长，黑桃对应挑战与边界。扑克占卜没有统一官方规则，必须明确所选约定，不套用塔罗花色、塔罗牌名、八字或其他体系。

数字牌以 A 的起点、2 的协调、3 的展开、4 的结构、5 的变化、6 的调整、7 的探索、8 的投入、9 的积累、10 的阶段完成为产品象征。J、Q、K 分别可代表尝试、关照、承担的角色，不根据宫廷牌断言某性别、某肤色或某个人必然出现。

把花色、数字主题与牌阵位置结合，归纳用户可观察的关系及行动。不得断言财运收益、赌博胜率或不可逆的灾祸，不追加不存在的牌。
